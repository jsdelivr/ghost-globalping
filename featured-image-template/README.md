# Featured Images for the Globalping Blog

The file "Globalping Featured Image Template.fig" is a Figma file containing different featured image variants for the Globalping blog.
Use this file as a basis when creating or updating featured images.

## How to use the file

- import the file into Figma
- duplicate the image variant you need
- replace text and visuals as needed, while keeping the defined layout and styling 
- export as png

## What's in the file

- multiple featured image variants that we've already used for the blog
- guidance on:
	- fonts and typographic usage
	- colors and backgrounds
	- image and font sizes
	- dos and don'ts to make sure our blog images stay consistent
